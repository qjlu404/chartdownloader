# chartdownloader

This is an archived repository. Im glad that this project was useful (at least for those that were able to get it working😂)
I look forward to getting back into programming useful tools again in the future.

make sure you have python3 and pip installed.
You may need to manually install the modules: `urllib3 lxml wheel wget pdf2image`.
 Run main.py and the rest is pretty straightfoward. 
 
 If you're on linux/mac you'll have to install Poppler manually.
 
 if you have github click the star button as a thank you :)

 Go to config.py to adjust the date to the latest chart date available.

 As of June 2026 the chart supplement search that this progaram piggybacks off of has been out of service due to "maintenance downtime or capacity problems" and this program will not function.
